这是用 [ShokaX](https://github.com/theme-shoka-x/astro-blog-shokax) 搭起来的新博客，之后会部署到 GitHub Pages：<https://zyxhangzhou.github.io/>。

写新文章时，在 `src/posts/` 下新建 Markdown / MDX 文件即可。也可以用 HyC：

```bash
bun hyc new "文章标题"
```
