## 多 Agent 架构审慎反思

TiDB 和 Anthropic 的经验共识指出：Multi-Agent 并非银弹。其代价包括通信开销、状态漂移、调试困难及 token 指数增长；真正适用场景限于强隔离、并行或专业化需求。工程师应优先打磨单 Agent 的 prompt 与 tooling 能力。
