Agent 不是黑箱，得看清它每一步在干啥。密钥管理也变了——不是藏好 .env 就完事，而是让 Agent 根本碰不到明文。

## Agent 怎么落地

### 用 Min Agent 观察台把 Claude Code 拆开看

<Tweet id="2118297021585166497" />

**这是在说什么**

Min Agent 观察台就像给 Agent 装了个透明玻璃罩子：能看到它读了哪些文件、调了几次 API、中间改了几版 prompt。不是讲‘多智能体协作’，就是实打实录下一次编码全过程。适合想搞懂 Agent 行为边界的人，尤其怕它偷偷删库或发错请求。

**我们能学到什么**

- 下次试新 Agent 工具，先找有没有类似观察台的调试能力
- 安全边界不靠猜，靠看见它每一步在做什么
- 不用会写代码也能判断一个 Agent 是否可信

## 密钥安全

### Agent 时代密钥不能放 .env，得靠运行时注入

<Tweet id="2119055175524798811" />

**这是在说什么**

Agent 会主动读取项目文件（包括 .env），所以传统方式等于把密码贴在门上。Infisical 和 Doppler 都是密钥管家：启动时才把密钥塞进进程环境变量，内存里也不留痕。区别在于 Infisical 可自建服务器，Doppler 托管但对 Cursor 等工具做了预适配。

**我们能学到什么**

- 立刻检查当前项目里有没有 .env 被 Agent 可读
- 选密钥工具前先问：团队愿不愿意运维一个服务？
- 密钥不落盘不是目标，是底线
